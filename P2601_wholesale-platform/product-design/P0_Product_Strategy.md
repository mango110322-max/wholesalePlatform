# P0_Product_Strategy

## 项目定位

本项目以 LIUHUAMALL 为核心参照，复刻并重构一个服装批发平台的产品体系。

项目不是单纯练习 UI 页面，而是把已有的买家端 Web 与移动端 UI 经验，扩展成能串联买家端、卖家端、管理端的完整产品设计能力。

## 作品集目标

- 展示对服装批发 B2B 电商业务的理解。
- 从买家端 UI 设计经验出发，补齐产品经理视角。
- 能说明买家端、卖家端、管理端之间的数据、流程和角色关系。
- 能把页面设计背后的业务目标、功能边界和后台支撑讲清楚。

## 参照对象

| 对象 | 说明 |
| --- | --- |
| 参照平台 | LIUHUAMALL |
| 官网 | https://www.liuhuamall.com/ |
| 平台类型 | 服装批发 B2B 电商平台 |
| 可观察重点 | 商品浏览、类目筛选、供应商店铺、询盘联系、订单/消息、卖家入口 |

## 核心设计主线

| 主线 | 关键问题 | 对应端 |
| --- | --- | --- |
| 买家如何找货 | 如何浏览、搜索、筛选、判断商品和供应商是否合适 | 买家端 |
| 卖家如何供货 | 如何发布商品、维护价格库存、处理询盘和订单 | 卖家端 |
| 平台如何治理 | 如何维护类目、审核商品、管理买卖双方和交易秩序 | 管理端 |

## 当前切入点

先从买家端开始，因为这是已有经验最强的部分；但每个买家端页面都要反推它背后的卖家端能力和管理端能力。

例如：

| 买家端页面/动作 | 背后的卖家端能力 | 背后的管理端能力 |
| --- | --- | --- |
| 商品列表 | 商品发布、库存价格维护 | 类目维护、商品审核 |
| 商品详情 | 商品资料维护、图片管理、规格价格管理 | 商品质量审核、违规处理 |
| 联系供应商/询盘 | 询盘接收、回复、报价 | 询盘监管、纠纷处理 |
| 店铺页 | 店铺信息维护、商品分组 | 卖家资质审核、店铺状态管理 |
| 订单 | 订单处理、发货/履约信息 | 订单监管、异常处理 |

## 近期产出方向

- 梳理 LIUHUAMALL 买家端公开页面和关键流程。
- 画出买家端、卖家端、管理端的端到端业务闭环。
- 定义 MVP 范围：优先覆盖商品、供应商、询盘、订单、审核。
- 为后续 UI 设计、开发和测试提供统一产品依据。
