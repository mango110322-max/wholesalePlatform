# Product Design

## 模块定位

`product-design/` 用于承载服装批发平台的产品设计产物，包括产品定位、用户角色、核心场景、MVP 范围、功能清单和业务流程。

## 当前使用方式

- 先从买家找货、询盘两个核心场景开始梳理。
- 先记录产品判断和功能边界，不急着进入页面细节。
- 后续稳定的产品结论可以同步沉淀到 `project-info/Plan.md` 或 `project-info/A1_Architecture.md`。
