# Product Design

## 模块定位

`product-design/` 用于承载产品设计阶段的 PRD 文档。

这里不重复记录 `project-info/` 中已经说明过的项目规则、协作方式和边界约定，只记录产品执行内容和定性结论。

## 当前文档

| 文档 | 用途 |
| --- | --- |
| `PRD0_Product_Strategy.md` | 记录战略层与范围层，包括用户、问题、定位、功能范围、MVP 优先级 |
| `Research1_初次卖家侧调研&分析.md` | 记录调研数据、访谈材料、用户画像资料和用户分层过程 |
| `PRD1_Milestones.md` | 记录项目里程碑划分，以及每个里程碑要完成的内容 |
| `PRDn_xxx.md` | 后续具体版本 PRD 或某个功能的独立 PRD |
