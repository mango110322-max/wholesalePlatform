# PRD1_Milestones

## S1. 文档定位

本文件用于记录项目的里程碑划分，以及每个里程碑要完成的内容。

## 里程碑划分

| 里程碑 | 目标 | 主要产出 |
| --- | --- | --- |
| M1 业务战略层 | 把目标用户、核心场景、核心问题、平台定位讲清楚 | `PRD0` 战略层内容、`Plan.md` 目标说明 |
| M2 业务范围层 | 明确第一版范围、MVP 优先级和三端边界 | `PRD0` 范围层内容、`A1_Architecture.md` 三端边界 |
| M3 买家端产品设计 | 明确买家端核心流程、页面结构和信息重点 | 买家端页面清单、核心流程、低保真结构 |
| M4 卖家端与管理端产品设计 | 明确卖家端和管理端的后台能力与页面结构 | 卖家端/管理端页面清单、流程、权限边界 |
| M5 UI 设计 | 产出关键页面的交互稿和视觉稿 | Web 端与移动端 UI 稿、组件规则 |
| M6 开发与验证 | 完成原型或前后端实现，并进行基础验证 | 工程代码、接口设计、测试与验收清单 |

## 当前阶段

当前处于 `M1 业务战略层` 和 `M2 业务范围层` 阶段。

当前重点：

- 先把 `PRD0` 的战略层写清楚。
- 再把第一版范围和 MVP 优先级收敛清楚。
- 完成后再进入买家端、卖家端、管理端的页面和流程设计。

## 每个里程碑的完成标准

| 里程碑 | 完成标准 |
| --- | --- |
| M1 | 能清楚说明为谁做、解决什么问题、平台的核心价值是什么 |
| M2 | 能清楚说明第一版做什么、不做什么，以及三端各自承担什么能力 |
| M3 | 买家端核心流程、页面和信息层级可直接进入 UI 设计 |
| M4 | 卖家端和管理端的后台能力、流程和边界清晰可落稿 |
| M5 | 关键页面的交互和视觉方案可进入开发阶段 |
| M6 | 有可演示的产品结果，并有基础验证结论 |
