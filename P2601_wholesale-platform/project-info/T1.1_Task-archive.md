## 商品主图字段 MVP 搭建

归档时间：2026-07-18 21:55

实际执行说明：

```text
本阶段功能已经跑通，但没有按照下方原 1–6 建议步骤逐项执行。
实际开发依据是 project-info/BS_BrainStorming/bs5_增加商品图片展示.md 中的自主分析与构思。
因此下方清单保持未勾选状态，仅作为旧规划归档，不代表实际执行顺序。
```

阶段目标：

```text
打通商品主图从卖家录入、后端保存、数据库落点，到卖家端、管理端、买家端展示的最小闭环。
```

阶段边界：

```text
本阶段使用图片 URL 作为商品主图，不做真实图片上传。
测试图片暂时放在前端 public/product-images 中，通过可访问的 URL 展示。
```

### 1. 数据库层：主图字段落点

- [ ] 在 `product` 表增加 `main_image_url` 字段。
- [ ] 将字段同步到 `development/database/init.sql`。
- [ ] 将字段说明同步到 `development/database/tables.md`。
- [ ] 在 DBeaver 中确认本机数据库已经有主图字段。

### 2. 后端层：接口支持主图字段

- [ ] 新增商品时，后端可以接收主图 URL。
- [ ] 商品保存时，主图 URL 可以写入 `product.main_image_url`。
- [ ] 查询商品时，后端可以把主图 URL 返回给前端。
- [ ] 确认原有审核、上架、买家可见规则不受影响。

### 3. 卖家端前端层：录入与管理主图

- [ ] 卖家新增商品时可以填写主图 URL。
- [ ] 卖家商品列表可以看到商品主图。
- [ ] 没有主图的商品有基础占位展示。

### 4. 管理端联动：审核时查看主图

- [ ] 管理端待审核列表可以看到商品主图。
- [ ] 管理员可以结合商品名称、类目、价格和主图进行基础判断。
- [ ] 审核通过或拒绝后，原有状态流转保持不变。

### 5. 买家端联动：展示带图商品

- [ ] 买家端商品列表可以展示商品主图。
- [ ] 买家端仍然只展示已上架、已审核、有库存的商品。
- [ ] 商品列表从纯文字展示升级为带左侧主图的商品卡片。

### 6. 联调验证

- [ ] 卖家新增一条带主图 URL 的商品。
- [ ] 回到 DBeaver 查看 `main_image_url` 是否保存成功。
- [ ] 管理端审核该商品。
- [ ] 卖家端将审核通过的商品上架。
- [ ] 买家端确认该商品和主图可以正常展示。

### 实际阶段结果

当前已按 bs5 思路跑通：

```text
卖家新增带主图商品
  -> 数据库保存 main_image_url
  -> 管理端审核时看到主图
  -> 卖家上架商品
  -> 买家端看到左侧商品主图
```

暂缓项：

- 真实图片上传。
- 对象存储或 CDN。
- 多张商品图。
- 商品详情页。
- 询盘或下单入口。
- 商品信息维护与审核联动。
