# I1_Index

## 项目名称

P2601_wholesale-platform

## 项目简介

服装批发平台练习项目，用于熟悉 AI 在产品经理、交互设计师、视觉设计师、前端开发、后端开发、测试等岗位工作流中的使用方式。当前已建立项目大脑和阶段工作区，准备展开具体电商产品设计。
