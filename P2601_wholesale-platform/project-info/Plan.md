## R1_Roadmap

本区用于放置项目从当前状态走向 1.0 可用系统的全局路线。  
当前执行任务仍以 `project-info/T1_Task.md` 为准，Plan 只负责看方向和范围。

### 当前判断

当前项目已经完成：

```text
卖家新增商品
  -> 管理端审核商品
  -> 卖家上架商品
  -> 买家端展示可见商品
```

这说明三端最小链路已经打通，但距离 1.0 可用系统还需要继续补齐：

```text
买家能找货、看详情、发询盘
卖家能发商品、维护商品、处理询盘
平台能审核商品、管理类目、监管基础内容
```

### 1.0 建设主线

当前更适合先做“撮合型 1.0”，暂不追求完整交易闭环。

```text
商品主图
  -> 商品信息维护
  -> 商品详情页
  -> 买家提交询盘
  -> 卖家处理询盘
  -> 店铺 / 卖家基础信息
  -> 类目、搜索、筛选
  -> 管理端基础治理
  -> 1.0 收口
```

| 阶段 | 目标 | 说明 |
| --- | --- | --- |
| 1 | 商品主图能力 | 让商品从纯文字展示变成带图片展示 |
| 2 | 商品信息维护 | 卖家可以修改商品名称、价格、库存、起批量、主图等信息 |
| 3 | 商品详情页 | 买家可以从列表进入详情，判断商品是否值得联系 |
| 4 | 询盘提交 | 买家可以围绕某个商品发起采购意向 |
| 5 | 询盘处理 | 卖家可以查看、回复和关闭询盘 |
| 6 | 卖家 / 店铺基础信息 | 买家可以判断卖家是否可信，平台可以管理卖家基础资料 |
| 7 | 类目、搜索、筛选 | 买家可以更高效地找货，而不是只能浏览全部商品 |
| 8 | 管理端基础治理 | 平台可以管理商品、类目、卖家、询盘等基础内容 |
| 9 | 1.0 收口 | 整理核心流程、补基础校验、测试和文档归档 |

### 1.0 可用标准

1.0 不追求支付、物流、售后等完整交易能力，先追求找货和询盘撮合闭环。

| 角色 | 1.0 应具备的能力 |
| --- | --- |
| 买家 | 浏览商品、筛选商品、查看详情、判断卖家、发起询盘 |
| 卖家 | 发布商品、维护商品、上下架商品、查看询盘、处理询盘 |
| 管理员 | 审核商品、管理类目、管理卖家基础信息、查看基础询盘内容 |
