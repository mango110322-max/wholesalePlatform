# Plan

## G1_Goal

从 0 到 1 搭建一个服装批发练习项目，包含买家端、卖家端、管理端，用于熟悉 AI 在多岗位产品建设流程中的使用方式，并补齐从 UI 设计到产品经理视角的完整产品串联能力。

LIUHUAMALL 和过往 PRD 作为案例资料使用，用来学习真实项目的思考过程和业务拆解方式，不作为一比一复刻的功能说明书。

当前阶段目标：

- 已建立统一项目结构和阶段工作区。
- 开始从目标用户、核心场景、产品问题出发展开产品设计。
- 重点从已有买家端 UI 经验出发，串联卖家端和管理端。
- 后续逐步完成产品规划、交互设计、视觉设计、前后端开发与测试练习。
