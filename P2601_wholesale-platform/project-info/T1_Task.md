## 下一阶段候选规划：商品信息维护与审核联动

阶段目标：

```text
让卖家可以维护商品信息，同时让平台能控制哪些修改需要重新审核，哪些修改可以直接生效。
```

建议把“修改商品信息、下架 / 重新上架、修改后重新审核”合并成一个阶段处理。

### 1. 商品编辑能力

- [ ] 卖家可以编辑商品名称、类目、主图、价格、库存、起批量等信息。
- [ ] 编辑后卖家端商品列表能看到最新信息。
- [ ] 买家端只能看到符合可见规则的商品。

### 2. 修改字段分类

需要重新审核的内容类字段：

- 商品名称。
- 商品类目。
- 商品主图。
- 后续的商品描述、详情图等内容。

可以直接生效的经营类字段：

- 价格。
- 库存。
- 起批量。

### 3. 审核联动规则

内容类字段发生变化时：

```text
商品自动下架
  -> status 变为 OFF_SHELF
  -> audit_status 变为 PENDING
  -> 管理端重新审核
  -> 审核通过后卖家再手动上架
```

经营类字段发生变化时：

```text
不改变 audit_status
不强制下架
直接更新价格、库存、起批量
```

### 阶段结果

本阶段完成后，预期跑通：

```text
卖家修改商品内容类信息
  -> 商品重新进入待审核
  -> 管理端审核
  -> 卖家重新上架

卖家只修改价格、库存、起批量
  -> 信息直接更新
  -> 商品保持原有审核和上下架状态
```
