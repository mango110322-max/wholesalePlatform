## 当前阶段最重要的关系

### 0. Java 后端与前端工具链类比

通过已经熟悉的 Java 后端概念理解前端工具链：

| Java 后端 | 前端 | 类比说明 |
| --- | --- | --- |
| JDK | Node.js | 提供代码运行环境 |
| Maven | npm | 管理依赖和运行脚本 |
| `pom.xml` | `package.json` | 记录项目配置、依赖和命令 |
| Maven 依赖 | npm 依赖 | 项目需要下载和使用的第三方包 |
| `./mvnw spring-boot:run` | `npm run dev` | 启动本地开发服务 |

### 1. 前端和后端

```text
Vue 页面
  ↓ fetch / axios
Spring Boot 接口
```

前端负责页面和交互，后端负责业务规则和数据处理。

### 2. 后端和数据库

```text
Spring Boot
  ↓ Service
MyBatis Mapper
  ↓ SQL
MySQL
```

后端不会让前端直接操作数据库，而是由 Mapper 层执行 SQL。

### 3. 开发和调试

```text
Apifox
  ↓ 模拟前端请求
Spring Boot
  ↓ 写入数据
DBeaver
  ↓ 检查 MySQL 数据
```

在前端页面做好之前，Apifox 可以先模拟前端行为。

## 常用 Git 指令

### 查看当前状态

查看当前分支、哪些文件被修改、哪些文件还没提交：

```bash
git status
```

查看本地分支：

```bash
git branch
```

查看本地和远程所有分支：

```bash
git branch -a
```

### 查看提交历史

查看每次提交的信息：

```bash
git log
```

用一行显示一条提交，更适合快速浏览：

```bash
git log --oneline
```

查看最近 5 次提交：

```bash
git log -5 --oneline
```

显示分支合并关系图：

```bash
git log --oneline --graph --all
```

查看某一次提交的详细改动：

```bash
git show 提交ID
```

例子：

```bash
git show a1b2c3d
```

### 创建和切换分支

创建新分支并切换过去：

```bash
git switch -c 分支名
```

例子：

```bash
git switch -c product-design-mvp
```

切换到已有分支：

```bash
git switch 分支名
```

例子：

```bash
git switch main
```

老版本 Git 也可以用：

```bash
git checkout -b 分支名
git checkout 分支名
```

### 拉取和推送分支

拉取远程最新内容：

```bash
git pull
```

第一次把当前分支推送到 GitHub：

```bash
git push -u origin 分支名
```

后续继续推送当前分支：

```bash
git push
```

拉取远程分支列表：

```bash
git fetch
```

切换到远程已有分支：

```bash
git switch 分支名
```

如果本地还没有这个分支，可以用：

```bash
git switch -c 分支名 origin/分支名
```

### 提交当前改动

把指定文件加入暂存区：

```bash
git add 文件路径
```

把当前目录下所有改动加入暂存区：

```bash
git add .
```

提交改动：

```bash
git commit -m "提交说明"
```

完整常用流程：

```bash
git status
git switch -c 分支名
git add .
git commit -m "提交说明"
git push -u origin 分支名
```

### 合并和删除分支

切回主分支：

```bash
git switch main
```

把某个分支合并进当前分支：

```bash
git merge 分支名
```

删除本地分支：

```bash
git branch -d 分支名
```

如果分支还没合并，但确认不要了，强制删除本地分支：

```bash
git branch -D 分支名
```

删除远程分支：

```bash
git push origin --delete 分支名
```

### 常用理解

| 指令 | 含义 |
| --- | --- |
| `git status` | 看当前仓库状态 |
| `git branch` | 看本地分支 |
| `git log` | 查看提交历史详情 |
| `git log --oneline` | 用一行显示一条提交 |
| `git log --oneline --graph --all` | 用图形方式查看所有分支的提交关系 |
| `git show 提交ID` | 查看某一次提交的详细改动 |
| `git switch -c 分支名` | 新建并切换到分支 |
| `git switch 分支名` | 切换到已有分支 |
| `git add .` | 把当前改动放进待提交区 |
| `git commit -m "提交说明"` | 创建一次本地提交 |
| `git push -u origin 分支名` | 第一次推送新分支到 GitHub |
| `git push` | 后续继续推送当前分支 |
| `git pull` | 拉取远程最新内容并合并 |
| `git merge 分支名` | 把目标分支合并到当前分支 |

## 常用启动命令

### 后端 Spring Boot

```bash
cd /Users/allen/Documents/wholesalePlatform/P2601_wholesale-platform/development/backend

```

```bash
cd /Users/allen/Documents/wholesalePlatform/P2601_wholesale-platform/development/frontend-vue
npm install
```

启动前端服务：

```bash
cd /Users/allen/Documents/wholesalePlatform/P2601_wholesale-platform/development/frontend-vue
```


```text

3. 启动 Vue 前端
4. 用浏览器或 Apifox 测试功能
```
