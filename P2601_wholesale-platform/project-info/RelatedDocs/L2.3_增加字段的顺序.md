对，既然清单已经出来了，下一步就按“底层到上层”的顺序做最稳。

我建议顺序是：

1. **先定字段名**
    
    先统一成：
    
    ```
    数据库字段：main_image_url
    后端 Java 字段：mainImageUrl
    前端 TS/Vue 字段：mainImageUrl
    ```
    
2. **改数据库结构**
    
    先让数据库真的有这个字段，否则后端 Mapper 一加 `main_image_url`，运行时查表/插入会报错。
    
    在 DBeaver 的 SQL 编辑器执行：
    
    ```
    ALTER TABLE product
    ADD COLUMN main_image_url VARCHAR(500) NULL COMMENT '商品主图URL'
    AFTER min_order_quantity;
    ```
    
3. **同步改数据库脚本和文档**
    
    改项目里的：
    
    ```
    P2601_wholesale-platform/development/database/init.sql
    P2601_wholesale-platform/development/database/tables.md
    P2601_wholesale-platform/development/database/sample-data.sql
    ```
    
    这样以后重新建库时也不会丢字段。
    
4. **改后端数据对象**
    
    按顺序改：
    
    ```
    Product.java
    ProductCreateRequest.java
    ProductResponse.java
    ```
    
    也就是：
    
    ```
    数据库行 -> Entity
    新增商品请求 -> Request DTO
    返回给前端 -> Response DTO
    ```
    
5. **改后端业务层**
    
    改：
    
    ```
    ProductService.java
    ```
    
    在 `createProduct()` 里增加：
    
    ```
    product.setMainImageUrl(request.getMainImageUrl());
    ```
    
6. **改后端 Mapper**
    
    改：
    
    ```
    ProductMapper.java
    ```
    
    补：
    
    ```
    INSERT main_image_url
    SELECT main_image_url AS mainImageUrl
    ```
    
    注意所有查商品的 SQL 都要补。
    
7. **改前端类型**
    
    改：
    
    ```
    productTypes.ts
    ```
    
    `ProductCreateRequest` 和 `ProductResponse` 都要支持 `mainImageUrl`。
    
8. **改卖家新增商品表单**
    
    改：
    
    ```
    ProductCreate.vue
    ```
    
    加输入框：
    
    ```
    <input v-model="form.mainImageUrl" type="text" placeholder="请输入商品主图链接" />
    ```
    
    提交时把 `mainImageUrl` 放进 `createProduct()` 请求体。
    
9. **改三端展示页面**
    
    改：
    
    ```
    ProductList.vue
    AdminHome.vue
    BuyerProductList.vue
    ```
    
    用 `<img :src="product.mainImageUrl">` 展示图片，不是直接 `{{ product.mainImageUrl }}`。
    
10. **最后跑通测试**
    

走一遍完整链路：

```
卖家新增商品，填图片 URL
-> 管理端看到图片并审核通过
-> 卖家端上架
-> 买家端看到带图片的商品
```

可以简单记成：

```
字段名
-> 数据库
-> 后端对象
-> 后端 SQL
-> 前端类型
-> 前端表单
-> 前端展示
-> 联调测试
```

为什么先数据库？因为后端 Mapper 一旦开始读写 `main_image_url`，数据库表里必须已经有这个字段。否则后端启动不一定报错，但真正新增/查询商品时会报 SQL 错误。
